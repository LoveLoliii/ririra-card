FF14 角色模型导出与导入说明
适用于：Ririra 闪卡工作台（Windows 桌面版）
整理日期：2026-10-17

一、先看完整流程

游戏内整理角色外观与姿势
→ 用卫月插件 Meddle 导出模型
→ 完整保留模型文件、贴图和 cache 文件夹
→ 工作台设置 Blender，再导入整个文件夹
→ 设计卡面，导出 .ririra、PNG 或 GIF。

.ririra 给“Ririra 桌面闪卡”导入，可用鼠标旋转查看。
PNG、GIF 用于群聊分享；GIF 是预先渲染的动画，不能手动转动。
游戏导出的 glTF / GLB 是模型文件，不是 .ririra 卡片。

二、需要准备什么

1. 能正常进入 FF14 的游戏客户端和卫月（Dalamud）。
2. 与当前国服游戏、卫月版本匹配的 Meddle 插件。
3. Ririra 闪卡工作台。
4. 已安装的 Blender，用于还原 FF14 原始导出的材质。
   本目录提供 blender-5.1.2-windows-x64.msi，另见“Blender安装说明.txt”。
   这个版本已在当前工作台的模型转换流程中测试。

已经有正常显示、贴图齐全的普通 GLB 模型时，通常可以直接导入，
不必再走 FF14 原始材质转换流程。

三、找到或安装 Meddle

已经装好 Meddle：直接跳到第四节。

在游戏聊天框输入 /xlplugins，打开卫月插件安装器，查找 Meddle。
国服请使用适配当前国服环境的版本；插件名称、翻译和可用性可能变化。
如果搜索不到，先检查你使用的国服插件源及兼容版本。
不要默认把国际服最新版直接装到国服环境中。

上游项目的安装方法供核对：
输入 /xlsettings，在实验性设置中找到自定义插件仓库，添加：
https://raw.githubusercontent.com/PassiveModding/Meddle/main/repo.json
保存后，再从 /xlplugins 搜索并安装 Meddle。
以上是上游说明，不代表该仓库中的构建一定兼容国服。

四、游戏内导出角色

1. 换好准备制作闪卡的外观，等待头发、装备、贴图完全加载。
   尽量选择轮廓清楚、手臂不遮脸、衣摆少穿模的姿势。
   想保留特定表情或动作时，应在该状态下导出。

2. 打开 Meddle 界面，在角色列表中选择自己或需要导出的角色。
   不同版本可能显示 Live Character、角色等名称。
   先核对选中的角色，避免导出到场景中的其他对象。
   NPC 是否可选取、附件是否完整，以插件当前实际显示为准。

3. 使用整个人物的导出入口。
   上游界面有 Export All Models（导出全部模型）。
   如果需要连同武器等附件，可能有 Export All Models With Attaches。
   后者可能同时带入坐骑、宠物、伞等对象，制作单人卡片前先收起不需要的附件。
   避免只导出某一个身体或装备网格，否则角色可能缺头、缺衣服或缺身体。

4. 在导出设置中确认：
   - Export type：优先选 GLTF（glTF 2.0）。不建议选 OBJ。
   - Pose Mode：要保留当前姿势，使用 Pose / Local 对应的模式。
     Reference Pose / None 对应参考姿势，可能让人物恢复站姿。
   - 贴图和材质相关设置先保持默认，不主动精简导出数据。
   - 如果有 Extra Cache Files，它表示额外缓存原始文件，并不等同于
     基本贴图缓存开关。通常先保留默认，无须为了导入工作台全部勾选。

5. 点击 Export，选择一个单独的空文件夹，等待完成。
   不同插件版本的按钮名称会有差异，请以界面实际选项为准。

五、导出后必须保留哪些文件

推荐把每个角色放在独立文件夹，例如：

我的角色/
  角色.gltf
  角色.bin          （如果导出生成了这个文件）
  cache/
    ……材质和贴图资源……
  ……其他导出文件……

实际文件名、目录层级以及是否生成 .bin，以导出结果为准。
不要手动把所有贴图扁平化到一个文件夹，也不要只复制 .gltf。
移动或发给别人时，将整个导出文件夹一起复制或压缩。

cache 中的资源与模型内的材质数据一起用于还原 FF14 材质。
即使选择 GLB，也不能据此认定 FF14 原始导出不再依赖 cache。
不要先用其他工具清除材质自定义属性或模型附加数据。

六、导入 Ririra 闪卡工作台

1. 首次使用，先安装 Blender。
   打开工作台，点击顶部“设置 Blender”，选择安装目录里的 blender.exe。
   例如默认安装位置可能是：
   C:\Program Files\Blender Foundation\Blender 5.1\blender.exe
   应选择 blender.exe，而不是 .msi 安装包。

2. 展开右侧“角色模型”，点击“选择文件夹”。
   选择包含角色 .gltf 和 cache 的完整导出目录。
   原始 FF14 导出优先使用文件夹导入，不只选一个模型文件。

3. 如果目录中有多个模型，在“文件中的模型”里选择需要的角色。
   等待材质还原和转换完成。耗时取决于模型、贴图大小及电脑性能。
   工作台已带有转换所需的辅助脚本，无须为此手工安装 Blender 插件。

4. 角色显示后，展开“摆放模型”调整缩放、位置和朝向。
   再设置卡面背景、边框、文字、灯光与特效。
   材质还原和工作台渲染有各自限制，效果不保证与游戏画面完全一致。

七、保存与分享

在右侧“导出文件”中选择：
- .ririra 卡片：给 Ririra 桌面闪卡导入，保留可交互的 3D 展示。
- PNG 图片：导出当前视角的静态卡面。
- GIF 动图：导出转动展示，便于发送群聊。

桌面闪卡读取制作好的 .ririra 时，不需要再启动游戏或 Blender。
建议另外留一份完整原始模型导出目录，方便以后重新制作。

八、常见问题

1. 人物发白、出现亮粉色/青色、脸部颜色异常
   先确认选择的是完整导出目录，cache 没有遗漏。
   再确认工作台已设置正确的 blender.exe，并等待转换结束。
   某些 FF14 材质需要还原，普通 glTF 查看器显示异常不一定是导出失败。
   若仍异常，核对 Meddle 与游戏版本，尝试重新导出；个别材质可能尚未支持。

2. 提示缺少 bin、贴图或 cache
   重新选择最初导出的完整文件夹，保留目录结构。
   不要仅把 .gltf 拖进来，也不要只拷贝 cache 中的部分图片。

3. 人物是站姿、动作不对
   检查导出时的 Pose Mode，确认不是参考姿势。
   待目标动作和表情显示正确后重新导出。
   当前工作台主要制作静态姿势闪卡，不提供完整的游戏动作、表情库播放。
   卡片转动与人物骨骼动作是两件事。

4. 人物缺身体、缺头发、缺装备
   检查是否只导出了一个网格，或选错角色。
   换用整个人物的导出入口，等待资源加载完成后重新导出。

5. 找不到 Blender 或转换失败
   确认已安装完整 Blender，并重新选择 blender.exe。
   优先使用随附说明中测试过的版本。
   若文件夹过大，可只保留同一次导出的目标角色及其完整依赖后重试，
   不要通过随意删除贴图或 cache 来减小体积。
